Bubblesort-Regel:

Bubblesort vergleicht immer zwei benachbarte Elemente (`array[j]` und `array[j+1]`). Ist das linke Element größer als das rechte, werden sie vertauscht. Größere Zahlen "steigen wie Blasen" nach rechts auf. Nach Pass 1 steht das größte Element garantiert ganz rechts!

Insertionsort-Logik:

Insertionsort baut das sortierte Array von links nach rechts auf. In der inneren `while`-Schleife wird das aktuelle Element (`key`) so lange nach links verschoben, wie das Vergleichselement größer als `key` ist (`arr[j] > key`) UND der Index `j >= 0` bleibt.

ZUSAMMENFASSUNG: SORTIERALGORITHMEN IN JAVA

1. Bubblesort Iterativ

Vertauscht fortlaufend benachbarte Paare, wenn sie falsch sortiert sind.

• Komplexität: O(n²) (Average/Worst)
• Merkmal: Größte Elemente wandern wie Blasen nach rechts.

2. Insertionsort Iterativ

Sortieren durch Einfügen in den bereits sortierten linken Teilbereich.

• Komplexität: O(n²) (Best-Case fast sortiert: O(n))
• Merkmal: Effizient bei sehr kleinen oder bereits vorgeordneten Listen.

3. Selectionsort Iterativ

Sucht das Minimum im unsortierten Teil und tauscht es an die nächste freie Position.

• Komplexität: O(n²) in allen Fällen.
• Merkmal: Minimale Anzahl an Schreibzugriffen / Swaps (n Vertauschungen).

4. Quicksort Rekursiv

Teile & Herrsche (Divide & Conquer) mittels Pivot-Element und Partitionierung.

• Komplexität: O(n log n) (Worst-Case O(n²))
• Merkmal: Sehr schnell in der Praxis, nutzt Rekursion.
